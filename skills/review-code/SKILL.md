---
name: review-code
description: Self-review code before handing off to Validator.
---

Before considering a task done, self-review:

1. **Functionality** — does the code meet the acceptance criteria? Test edge cases.
2. **Correctness** — are there any obvious bugs, race conditions, or logic errors?
3. **Style** — does the code match the project's style? (naming, formatting, structure)
4. **Cleanliness** — any dead code, debug logs, TODOs, or commented-out code?
5. **Tests** — do existing tests still pass? Are new tests needed?
6. **Dependencies** — no new dependencies added without justification.

Fix any issues found before marking the task complete.
